# 타수형 적·보스 침식 손상 확인

2026-10-09, 로컬 반영. 커밋·푸시하지 않음.

## 타수형 적

기존 구현은 라운드 HP 배율을 타수에도 적용했다. 기본 3회에 HP 1.5배가 적용되면 반올림하여 HP가 5가 되고, 실제로 5회 피격해야 죽었다. 설명은 기본 3회를 표시해 불일치했다.

요청에 따라 설명을 늘리는 대신 타수를 고정했다.

- 일반 타수형 적 14종은 정의된 기본 HP를 타수로 사용한다.
- 보스가 소환하는 타수형 적(찌르는 갑주탄·잔향)도 소환물 HP 배율을 적용하지 않는다.
- 타수형 상태에서는 HP 배율·퍼센트·고정량 증가 버프가 최대 타수를 바꾸지 않는다.
- 잿불처럼 다른 형태로 전환하면서 타수형이 되는 적의 고정 타수도 유지한다.
- 일반 HP를 사용하는 적·소환물의 난이도 보정은 유지한다. 일반 HP 형태로 돌아오면 원래 HP 보정도 적용된다.
- 마법/트루 대미지만 인정하는 다기류의 판정과 기존 다단 타격 판정은 유지한다.

검증: 14종의 기본 타수, HP 배율 0.75/1/1.5/3, 연합방어 보급 HP 배율, HP 버프, 사망 후 생성, 보스 소환물, 고정 타수만큼 피격 시 처치, 일반 적 HP 보정, 실시간 정보 수치와 다단 타격 회귀 테스트. 관련 테스트 345개 통과.

## 보스의 침식 손상

원본 규칙 조사 자료에 “最终攻势中，敌方领袖不会受到侵蚀损伤”(최종 공세의 적 보스는 침식 손상을 받지 않는다)라고 명시되어 있다.

- 현재 구현은 보스전 보스 태그(`isBoss`)의 침식 게이지 누적을 취소한다. 임계치 폭발과 침식에 따른 방어력 감소도 발생하지 않는다.
- 일반 적은 침식 손상을 받는다. 보스의 다른 원소 손상은 취소하지 않는다.
- 침식 면역은 수정하지 않았다. 기존 보스 침식/다른 원소/일반 적 침식 비교 테스트가 통과했다.
