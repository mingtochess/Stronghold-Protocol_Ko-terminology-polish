# 로컬 적 특성·상태 및 에기르 연속 전투 수정 (2026-10-06)

운영 서버 배포·커밋·푸시 없이 로컬 작업본에만 적용했다.

## 적용한 수정

- 전투 중 본인/관전/다른 플레이어 전장의 대기석 오퍼레이터를 숨기고, 전투 카메라의 대기석 확장을 사용하지 않는다. 휴식 관람 화면에는 전장과 대기석을 함께 표시하며 모두 1배속으로 재생한다.
- 상태 이펙트를 Spine 몸체 뒤가 아닌 앞에 그린다. 기존에는 불투명한 몸체에 가려 빙결·굴절·보호막의 대부분이 보이지 않았다.
- 굴절: 기존 푸른 타원 대신 짙은 보라색 육각 막과 작은 육각형을 사용한다. 몸체 채우기 알파는 0.30이며, 침묵으로 굴절이 비활성화되면 표시도 사라진다.
- 빙결: 몸 전체를 감싸는 얼음 다면체를 확대하고 외곽과 내부 균열을 강화했다. 지속시간 동안 Spine 업데이트 시간은 0, 해제 후 정상 시간으로 복귀한다.
- 보호막: 실제 SHIELD 플래그도 지속 이펙트에 연결한다. 아이콘 4개 제한이 몸체 이펙트를 숨기지 않게 한다.
- 기절·수면·속박·한기·화상·침묵·공포·감속·약화·취약·금지 회복·신경/괴사 상태에도 구별 가능한 몸체/발밑 표시를 연결했다. 모델에 해당 상태용 연출이 있으면 이를 우선한다. 모든 사용자 정의 버프가 원작과 정확히 같은 이펙트를 갖는다는 뜻은 아니다.
- 적 머드락: 공격력 증가를 공격당 +10%에서 +60%, 최대 6중첩으로 바로잡았다. 증가 중첩을 표시 가능한 상태로 전송하며, 보호막 지속/파괴/재생은 기존 실제 능력치·법술 피해 흡수와 연결한다.
- 미러 가드/상위 개체: 첫 피격 중첩은 능력치 감소 없이 유지하며 2중첩부터 누적 방어·법술 저항 감소를 적용한다. 데이터의 15/45 및 15/60중첩 파손 표시를 추가했다.
- 적 자작 투석기: 3타를 같은 순간에 적용하던 것을 데이터의 0.3초 타격 간격으로 변경했다. 발사한 후속 타격은 공격자가 사망해도 남는다.
- 에기르 일반 전투→협동 작전: 포식 완료 여부, 포식 획득 공격력/저지 수, 사용한 공유 부활과 개별 부활 이력을 결과에 저장한다. 결과 압축→서버 검증→협동 작전 입력→실제 맹약 적용까지 전달한다. 이미 포식한 전투를 다시 포식하지 않는다. 새 라운드에는 이 상태를 전달하지 않아 정상적으로 새 포식이 실행된다. 실행 중인 스킬은 기존대로 전달하지 않는다.

## 전체 카탈로그 점검의 범위

`tools/audit-enemy-traits.mjs`로 현재 적 249종/설명 497행을 목록화하고 적 키트·보스 키트·엔진/환경 조건 처리 중 어디로 연결되는지 확인했다. 생성 및 초기 tick의 핸들러 오류는 0건이었다. 상세 목록은 `LOCAL-ENEMY-TRAITS-AUDIT.json`에 있다.

기존 전투 테스트와 추가 회귀 테스트는 보호막·굴절·부활·변신·특수 공격·면역·은신·장판 등의 실제 동작을 검증한다. 이 카탈로그/테스트 통과는 **497행 모두의 원작 수치와 모든 발동 시점을 독립 대조했다는 증거가 아니다**. 머드락의 이전 테스트처럼 잘못된 수치를 그대로 기대한 테스트가 있을 수 있어 외부 설명과 대조해 확정된 차이를 고쳤다.

현재 전장에 없는 사건 조건(축음기 점령, R 시리즈 미활성 장갑 접촉, 피의 제단, 긴급 난방기, 고정 사슬, 증생 갑각, 축제/촬영 구역, 전용 이동 다리·소금 포 등)은 조건 자체를 새로 만드는 변경을 하지 않았다. 비행/자연 회복/도발처럼 엔진이나 데이터에서 구현되는 항목은 별도 적 키트가 없다고 누락으로 판단하지 않는다.

## 원작 참고와 시각 검증

- 머드락: https://arknights.wiki.gg/wiki/Mudrock/Enemy — 공격마다 +60%, 최대 6회. 일반 스토리와 위수협약의 보호막 수치 차이를 임의로 덮어쓰지 않았다.
- 미러 가드: https://prts.wiki/w/弧光镜卫 — 첫 중첩 유예, 층당 방어 -50/법술 저항 -2, 외형 변경 임계값.
- 굴절: https://arknights.wiki.gg/wiki/Refraction — 보라색 육각형 막, 침묵 시 비활성.
- 빙결: https://arknights.wiki.gg/wiki/Freeze — 얼음에 둘러싸임, 애니메이션 정지.

위키 본문은 확인했다. 이미지 검색도 시도했으나 관련 없는 검색 결과가 반환되어 원작 전투 스크린샷 비교의 증거로 사용하지 않았다. 따라서 원작 스크린샷과의 전체 대조가 완료됐다고 주장하지 않는다.
