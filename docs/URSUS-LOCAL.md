# 우르수스 로컬 실험

로컬 실험은 `local/ursus-experiment` 작업 공간에서 개발했다. 운영 반영용 데이터와 추가 리소스 목록은 `content/production/`에 준비하며, Docker 빌드가 자동으로 적용한다. GitHub push 후 기존 EC2 수동 업데이트 명령을 사용한다. 자세한 방법은 [EC2 업데이트 안내](../deploy/ec2/README.md)를 참고한다.
일반 `npm start`는 기존 `data/`를 사용한다. 우르수스 실행은 `.cache/ursus-data/`에 생성한 별도 데이터를 사용한다.

## 실행

Node.js 22 이상이 설치된 PC에서 저장소 폴더를 열고 실행한다.

```sh
npm ci
npm run dev:ursus -- --open
```

Windows에서는 `scripts/start-ursus-windows.bat`를 더블클릭해도 된다.
첫 실행은 공식 데이터와 추가 리소스를 다운로드한다. 이후에는 `.cache/`와 `public/assets/`를 재사용한다.
서버는 `127.0.0.1:3001`에만 바인딩한다. 포트 변경은 `URSUS_PORT` 환경 변수로 한다.
테스트 화면: `http://127.0.0.1:3001/dev/ursus.html`. 실제 게임 로비: `http://127.0.0.1:3001/`.
테스트 화면에서는 2/3/5/6/10명, 중첩 수, 일반/정예와 각 오퍼레이터의 참가 여부·스킬을 선택한다. 전체 스킬 충전·발동과 아군 HP 50% 버튼으로 치료·재능도 시험한다.
실제 게임 로비는 기존 브라우저 리소스 다운로드 안내를 유지한다. 새 오퍼레이터 리소스는 로컬 서버에서 제공한다.
종료는 서버 터미널에서 Ctrl+C. 원래 버전 실행은 `npm start`.

## 진영

베토치키와 굼의 기존 소속을 유지하면서 우르수스를 추가한다. 신규 8명도 일반/정예 모두 추가한다.
3명: 전투 시작 시 제국 드론 1기. HP와 공격력 보정은 `1.25 + 0.015 × 우르수스 중첩`.
6명: 해당 플레이어의 제국 드론과 우르수스 오퍼레이터 ASPD +50.
동일 오퍼레이터의 복수 배치는 기존 진영 계산처럼 별도 인원으로 세지 않는다.
드론은 공식 `enemy_1112_emppnt`의 기본 HP 13,000, 공격력 1,000을 사용한다.
따라서 0중첩은 HP 16,250 / 공격력 1,250, 20중첩은 HP 20,150 / 공격력 1,550이다.
우르수스 자체는 특질로 중첩을 얻는다. 드론은 전장 중앙에서 오른쪽 1칸 위치에 소환되며, 중앙에 가장 가까운 빈 칸을 예약한 뒤 공중에서 적을 향해 이동한다. 협동에서는 각 플레이어 전장 절반의 중앙에서 오른쪽 1칸 위치를 사용한다. 기본 이동 속도는 원본 0.5 × 시뮬레이터 MOVE_SCALE 0.5 = 0.25칸/초이며, 반경 2칸 안에 적이 있으면 멈춰 본진까지 남은 경로가 가장 짧은 적을 공격하며, 범위 안에 적이 없으면 전체 적 중 본진까지 남은 경로가 가장 짧은 적을 향해 이동한다. 해당 사거리를 바닥 원으로 표시한다. 공중 유닛은 지상 오퍼레이터보다 위에 렌더링한다. 목표 지점을 표시하고 경고음을 낸 뒤 수직 낙하한다. 발사 순간의 목표 위치와 공격력을 고정하고 3초 후 반경 1.2칸에 광역 물리 피해를 준다. 이동한 목표를 추적해서 맞추지 않으며, 발사한 포탄은 드론이 쓰러져도 착탄한다. 원본 적 제국 드론과 같은 무출처 피해이며 드론에 처치·피해 기여를 기록한다. 표적이 사라지면 다시 추적하고 적이 없으면 제자리에 머문다. 공중 이동은 기존 염국 소환수처럼 세계 좌표와 공격 범위를 갱신하며 지상 유닛을 저지하지 않는다.

## 스킬·재능

한국어 이름·스킬·재능·특성 설명은 ArknightsAssets/ArknightsGamedata의 `kr/gamedata/excel`에서 가져온다. 표시 수치는 실제 전투 블랙보드로 채우며 전투 수치 자체는 변경하지 않는다. 첫 실행에 받아 `.cache/ursus-source/kr-*.json`을 재사용한다.

공식 데이터의 모든 선택 스킬 19개를 전용 전투 코드로 구현한다. 일반 Lv4 / 정예 Lv7의 수치·SP·지속시간·사거리·재능 블랙보드를 사용한다. 기본 선택은 S1이며 로비의 기존 스킬 선택도 지원한다. 정예는 공식 3레벨 모듈을 사용하고 모든 대체 모듈·모듈 없음 선택을 지원한다. 일반은 모듈을 적용하지 않는다. 모듈별 능력치와 재능·특성 블랙보드는 기존 로드아웃 시스템에 반영한다. 스킬 아이콘은 모든 19개 스킬을 아이콘 ID → 이미지 경로와 스킬 ID → 아이콘 ID 양쪽에 등록한다.

## 우르수스 전용 장비

통합전략 소장품 **우르수스 곡도 (乌萨斯弯刀, `rogue_1_relic_c01`)**의 이미지·설명을 사용한다.
3단계 일반/정예 장비로 추가하며 공격력·최대 HP +15% / +25%이다. 효과는 이 실험용으로 정한 것이며 원래 통합전략의 저주 효과를 가져온 것은 아니다.
단독 장착은 능력치만 올린다. 변형 구조체와 함께 장착하면 우르수스 소속을 추가한다. 기존 장비와 같은 동적 조합 경로를 사용하므로 진영 인원·중첩·6명 공속 효과에도 반영된다.
이미지는 공개 리소스 저장소의 `arts/ui/rogueliketopic/itempic/rogue_1_relic_c01.png`에서 다운로드한다.

## 클라우드 작업 공간의 임시 접속

이 환경에서만 실행한 loopback 서버를 임시 HTTPS 터널로 열어 사용자 PC에서도 확인할 수 있다. HTTP 전용 터널에서는 Ursus 전용 HTTP 폴링 어댑터가 기존 `/ws` 세션에 전달한다. 게임 접속·방·대전 프로토콜은 그대로 사용하지만 실제 WebSocket 직결보다 지연이 추가되므로 성능 측정용으로 쓰지 않는다.
임시 주소는 작업 응답에 제공하며 서버/터널 종료나 환경 회수 시 사용할 수 없어진다. 저장소 실행 스크립트는 자동으로 공개 터널을 만들지 않는다.
테스트 로비는 4017개 전체 리소스를 선다운로드하지 않는다. 필요한 파일을 서버의 `.cache/ursus-preview-resources/`에 한 번 저장하고, 브라우저의 고정 `stronghold-ursus-preview-assets-v1` 캐시에 요청한 파일만 저장한다. 같은 주소에서는 새로고침·재시작·스킬 변경에도 재사용한다. 기존 같은 출처의 리소스 캐시도 먼저 조회한다. 이전 임시 도메인의 저장소는 브라우저의 출처 격리 때문에 자동으로 가져오거나 지울 수 없으므로 브라우저 사이트 데이터 관리에서 정리해야 한다.
우르수스 맹약 이미지는 공식 `arts/camplogo/logo_ursus.png`를 사용한다.

## 구조와 출처

- `content/custom/ursus/operators.json`: 오퍼레이터 소속·단계·기본 스킬·특질 선택.
- `tools/build-ursus.mjs`: 기존 데이터 복사 및 공식 데이터 기반 추가 레코드 생성. `data/`는 쓰지 않는다.
- `tools/fetch-ursus-assets.mjs`: 공개 초상화·스킬 아이콘·전투 Spine 다운로드 및 아틀라스 정규화.
- `server/sim/content/ursus.js`: 진영 효과. 전용 토큰 데이터가 없으면 아무 효과도 설치하지 않는다.
- `server/sim/content/kits/ursus.js`: 신규 모든 선택 스킬과 재능의 실험용 전투 코드.
- `public/dev/ursus.html`: 실제 시뮬레이터와 렌더러를 이용하는 비교 화면.

## 공식 3D 맵·전투 음향

```sh
npm run assets:battle
npm run dev:ursus
```

최초 에셋 준비에는 Python 3와 venv가 필요하다. 공식 CDN의 필요한 14개 번들만 받아 메시·보드 텍스처를 추출하고, 제국 드론 조준/발사/폭발 및 전투·연방전 음악을 공개 리소스에서 저장한다. 다운로드는 캐시를 재사용한다. 로컬 3D 매니페스트는 실험 데이터에만 연결한다. 전체 점검 결과와 미재현 기믹은 [LOCAL-AUDIT.md](LOCAL-AUDIT.md)를 참고한다.

2026-10-05 변경: 우쿠시크는 준비 시간 진입 시 자신의 활성 맹약 각각 +4(일반/정예 동일), 레토는 발동당 +2, 전투당 10회(총 +20). 드론은 특별한 도발 무시를 제거하고 일반 아군 타겟 우선순위를 따른다.
