# 0.3.3 Korean-fork revisions

## 0.3.3k — restart vote (2026-11-05, PR #28)

The former restart vote was easy to miss and gameplay continued while participants answered it. The user-approved
fork requirements add a visible themed panel and freeze the game until voting resolves. These are room-management
product decisions, not an assertion of official rules; see the [contract](../design/restart-vote.md).

Defaults: unanimous agreement, eliminated players included if still present, 45 seconds to vote, 120/180-second
room/personal cooldowns and two requests per player per game. Custom rooms can edit these before starting.
Departed eliminated players and their votes are removed; spectators do not vote.

The pause preserves the strategy-complete five-second wait added in 0.3.3j1 and existing selection/combat timers.
Shared popup styling applies theme textures and frames without making the panel transparent or blocking chat/emotes.
Native catalogs cover Korean, English, Simplified Chinese and Japanese.

[Validation](../reviews/pr28-validation.md) records focused tests, browser captures, broader failures compared with
the pinned current master, and limitations. No golden digest is regenerated to hide a baseline failure. CI workflow,
timeouts, concurrency, test coverage policy and required checks are unchanged.
