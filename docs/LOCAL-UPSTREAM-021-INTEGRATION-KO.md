# 원본 0.2.1 로컬 통합 결과

대상: `sganggs/Stronghold-Protocol`의 `v0.2.1` (`c2a2ef778cf728ff29b953b9842b2a39b1e9cbea`). 기준 로컬 커밋: `34009dc`.

원본 기능 수정들을 기존 구조에 선택적으로 이식했다. 전체 릴리즈 병합이나 새 구조로의 전환은 아니다. 커밋·푸시·운영 서버 배포는 하지 않았다. 패치노트는 `0.2.1a`, 테스트 상태로 추가했다.

## 적용

| 영역 | 반영한 동작과 충돌 처리 |
| --- | --- |
| 풀잠재 | 일반·정예·선발·우르수스 데이터 빌더에 최대 잠재 능력치와 재능·모듈 후보 선택을 적용. 소환물은 소유자의 잠재에 맞는 재능을 선택하되 소유자의 능력치 보너스를 그대로 상속하지 않는다. 기존 공격 타이밍 등 사용자 필드를 유지했다. |
| 전투 실행기 | 데이터 로딩 중 시작·중단·재시작 요청이 겹치는 경우의 처리. 로컬에 없는 backups 데이터 의존성은 제외했다. |
| 기습·귀환 | 실제 참여 전장 내 배치와 본인 전장 귀환·부활을 보장. 기존 배치 즉시 스킬, 배치 애니메이션, 배치 순서는 유지했다. |
| 소모품·상점 | 슬롯이 가득 찬 소모품도 교체 선택. 실패하면 원래 장비 복원, 성공하면 선택한 장비만 제거. 승급으로 열린 상점 슬롯을 채우고 임시 대기석을 빈 대기석으로 이동. 가득 찬 대기석에서 구매·보상 처리와 캐시 장비 보상 범위를 수정했다. |
| SP·상태 | 괴사는 저장된 충전까지 감소. 적에게 냉기가 중첩돼 빙결이 성공한 경우 냉기 소비. 빙결 면역은 별도 처리한다. |
| 적·소환물 | 죄수의 경고·해방 전환을 타격 전에 적용. 타격 횟수형 적의 HP 보정과 보스 소환물의 라운드 보정을 분리. 기존 사용자 지정 난이도·인원·보스 HP 설정은 유지했다. |
| 부활 | 관련 장비·맹약 부활을 실제 사망 이후 재배치로 처리하여 초기 SP와 배치 시 효과를 다시 적용. 우선순위와 중복 부활 방지 검증을 추가했다. |
| 치유·직군 | HP 회복과 일반 치유의 차이, 연쇄 치유의 인접 대상·만피 경유, 차지 캐스터 에너지 축적·방출, 검호·수확자 치유 제한과 중장 다중 타격을 수정했다. |
| 개별 스킬·재능 | 벤델라 피해 판정, 퍼퓨머·블레미샤인·스즈란·스카디 더 커럽팅 하트의 HP 회복, 그라벨 추가 타격, 스와이어 더 엘리건트 위트의 코인·폭탄, 비질 늑대 전술 지점·복귀, 루멘 모듈 및 Touch 조건 등 원본 변경을 이식했다. 머드락 3스킬 폐쇄 중 저지 해제 누락도 수정했다. |
| 애니메이션 색인 | 적의 번호별 스킬 역할 색인과 기절 별칭을 확장. 기존 스킬별 모션·타격 시점·공중 렌더링 처리는 유지했다. |

## 기존 구현을 유지한 부분

- 한국어 UI, 우르수스 조건부 확장, 기존 선발 5명, 스킬·스킨 설정 및 캐시 경로.
- 사키코 추적 음표, 커스텀 맵·이펙트·관전 처리.
- 사운드 타이밍 롤백, 제국 드론의 보스 우선·복수 보스 중 최근접 우선.
- 비질은 배치된 늑대 기물이 있을 때 전술 지점을 설치하는 기존 수정 유지. 미배치 늑대를 자동 생성하는 원본 경로는 채택하지 않았다.
- 기존 스킬 범위 탐색과 공격 선딜레이·타격 후 모션 보존. 원본의 트리거 이름을 그대로 맞추기보다 실제 발동 범위와 동작을 검증했다.

## 제외·제한

858개 파일 규모의 모듈 분리, 신규 DIY 71명·소유권/대체 오퍼레이터 체계, 다국어·단축키·화면 전면 교체는 이식하지 않았다. 맹약 접기 UI는 기존 사용자 요청과 충돌하므로 제외했다. 새 적 애니메이션 역할은 색인까지 적용했으며 새 렌더러의 모든 역할 전환을 통째로 이식한 것은 아니다. 공식 업데이트 ZIP/manifest도 변경하지 않았다.
