# 공중 유닛 렌더링 순서 · 로컬 수정

비행 유닛을 지상 유닛보다 우선해서 그리던 렌더러에는 공중 부양 상태 정보가 도달하지 않았다. 서버의 `UF.FLYING` 플래그가 기본 `motion === FLY`만 검사하고 있었기 때문이다.

- 기본 비행, 적의 부유·공중 부양, 아군 이륙 상태를 공중 표시 플래그에 포함했다.
- 초기 생성·관전·재접속 정보에도 현재 공중 표시 여부를 포함한다.
- 렌더러는 최신 스냅샷을 따르며, 공중 부양 종료·착지 시 지상 순서로 돌아온다.
- 같은 공중 유닛끼리는 기존 원근 순서를 유지하며, 모든 공중 유닛은 지상 유닛보다 앞에 그린다.
- 간소화 렌더러에도 비행 유닛의 상위 z-index를 적용했다.
- 이동 방식, 경로, 대공·저지·스킬의 전투 판정은 변경하지 않았다. 단순 드래그 시 들어 올리는 표현을 공중 상태로 바꾸지 않는다.

관련 검사 45개 통과. 기본 비행·공중 부양·부유·아군 이륙과 효과 만료, 실제 UnitView의 순서 복원, 모든 전장 카메라에서 지상/공중 순서, 기존 가림·전투 동작을 확인했다. 클릭 판정 관련 검사 23개도 통과했다.
