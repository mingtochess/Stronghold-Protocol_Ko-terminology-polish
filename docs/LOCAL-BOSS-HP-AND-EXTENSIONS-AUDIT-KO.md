## 보스와 히든 보스 HP

공식 리소스의 `.cache/gamedata/excel/activity_table.json` → AUTOCHESS_SEASON.act2autochess.bossInfoDict와 현재 데이터를 비교했다. 네 난이도에서 일반 보스 7종 및 히든 보스 3종의 협동 HP는 모두 일치한다. 협동은 생존자 수에 따른 추가 축소가 없으며, 모든 전장은 하나의 공유 HP를 사용한다. 전장별 보스 복제 수로 HP를 나누거나 피해를 복제하지 않는다.

즐거움의 히든 값은 데이터 존재 여부를 검증하는 값이며 실제 진입 가능성을 의미하지 않는다.

확인한 경로: GameData.bossPoolHp → finalAssault.bossPoolHp → Match.startFinalAssault → 공유 풀/전장 명세 → Battle 보스 본체 HP 동기화 → 피해 계산/클라이언트 누적 피해 ACK → 스냅샷/보스 HUD. 일반 적용 라운드 HP 배율은 공유 보스 HP에 다시 곱하지 않는다. 서버의 누적 피해 보고는 이미 인정한 값 이후의 증가분만 반영한다. 기존 보스 HP/보고/스택 회귀 테스트와 새 공식 데이터 비교 테스트를 함께 실행했다.

**검증 한계:** 솔로는 현재 공식 협동 표의 ×0.25를 적용한다. 이 배율과 협동 생존자 감소 시 원작의 정확한 조정 여부는 공식 표만으로 확정할 수 없다. 구현 일관성은 확인했지만 원작과 완전히 동일하다고 주장하지 않는다. 수치를 임의로 바꾸지 않았다. 이전 연구 문서의 생존자 수/4 추정은 현재 `aliveScaling:false` 설정에 적용되지 않는다.

## 커스텀 확장

맹약/전장 탭에서 각 확장을 독립적인 체크박스로 선택한다. 여러 전장과 맹약을 동시에 선택 가능하다. 방 버튼은 실제 적용된 전체 확장 개수를 표시한다. 방장만 적용 가능하며 참가자는 동일 설정을 읽는다. 변경 시 참가자의 준비 상태를 해제한다. 취소는 적용하지 않으며, 다른 참가자의 상태 갱신 때문에 편집 중 선택이 초기화되지 않도록 했다.

현재 실제 등록 확장은 우르수스 하나이며 커스텀 전장은 없다. 전장 등록은 stages 테이블에 `customExtension:true` 또는 `{category:'stages',description,modeIds}`를 지정한다. 선택한 전장만 모드의 추첨 목록 및 전투 데이터에 들어간다. 기본 전장은 유지한다. 검증용 A/B 전장은 테스트 내부에만 존재한다.

스킬/모듈/스킨 환경 설정 저장소를 변경하지 않는다. 매치 데이터만 분리해 필터링한다. 켜기/끄기 반복 시 스킬과 스킨 유지, 참가자 양쪽의 설정 유지, 실제 Match 생성 옵션 전달을 검증했다.

스크린샷: `/workspace/artifacts/custom-extensions-bonds.png`, `/workspace/artifacts/custom-extensions-multiple-maps.png` (후자는 테스트 전장 두 개의 동시 선택 예시).

## 무료 새로고침

모든 지급 경로를 확인했다: 기적 맹약의 확률 발동(기본 18% + 중첩당 0.3%p), 특질, 전략의 특별 새로고침, 선택 보상. 기적은 마지막 무료 새로고침을 사용한 직후에도 다음 무료 새로고침을 지급할 수 있으며 현재 설명의 '새로고침 시'와 맞는다. 보고된 사례의 플레이 로그가 없으므로 모든 발생이 정상이라고 단정하지 않는다.

사용자 요청에 따라 출처 표시와 관련 메타데이터 추가를 제거했다. 기존 지급 조건과 발생 확률은 유지한다. `grantFreeRefresh(0)`는 조회이며 지급하지 않는다. 보고된 사례 자체의 오류 원인은 아직 확정되지 않았다.

## 2026-10-06 사용자 요청에 따른 인원별 HP 변경

이하 새 규칙이 앞서 기록한 솔로 ×0.25 / 협동 고정 HP 정책을 대체합니다. 일반 보스와 히든 보스 모두 솔로는 난이도별 bloodPoint ×1, 협동은 보스전 시작 시 생존 참가자 수(1–4)만큼 곱합니다. 전투 중에는 크기를 재조정하지 않으며 모든 전장은 하나의 HP 풀을 공유합니다. 이는 사용자 지정 밸런스이며 원작 동일성 주장과는 별개입니다. 일반 적·호위 및 보스 공격력 배율은 변경하지 않습니다.
