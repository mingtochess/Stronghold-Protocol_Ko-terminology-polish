# 비활성 전장 타일 표시·선택 수정

- 원본 수면 메시가 하나의 연결된 장식물로 분류되어 양쪽 전장을 함께 표시하던 문제를 수정했다. 수면의 삼각형을 활성 전장 경계에서 자르며 원본 UV·라이트맵 좌표와 색상을 보간해 유지한다.
- 2D 타일 그리드에도 3D 전장과 같은 표시 영역을 적용한다. 비활성 영역은 표시·배치 가능 타일로 취급하지 않는다.
- 타일 클릭, 기물 선택에 쓰는 바닥 판정, 드래그 위치 판정은 현재 표시 영역 안의 실제 표시 타일만 받는다. 보이지 않는 오른쪽 타일이 정보창을 열거나 선택되는 경로를 차단한다.
- 일반 전장에는 왼쪽 전장과 적 미리보기 영역을, 협력 전장에는 양쪽 일반 전장을, 보스전에는 보스 전장을 유지한다. 전장 경계에 걸친 장식용 구성요소의 기존 보존 규칙은 유지한다.

검증: 렌더링·타일·드래그 테스트 52개와 오퍼레이터 표시·대기석 회귀 테스트 41개 통과. 사막 기본 맵과 침수 사막 맵에서 일반·협력·보스 표시 영역과 수면 메시 좌표를 브라우저로 검사했다. 화면 안의 비활성 오른쪽 타일은 클릭 이벤트가 발생하지 않고, 활성 전장의 타일은 정상적으로 클릭 이벤트가 발생하는 것도 확인했다.
