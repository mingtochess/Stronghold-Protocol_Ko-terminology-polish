# 나란투야 전략 점검

검토한 데이터: band_narant / aceffect_band_60, 사르곤 맹약의 장비 공유 전용 파라미터.

- 초기 HP 26.
- 짝수 라운드 준비 진입 시 장비 후보 2개 중 1개 무료 선택. 일반 상점 무료 새로고침 횟수를 추가하는 효과는 아니다. 장비 후보는 전용 풀 및 현재 상점 단계 제한을 사용한다.
- 활성 6사르곤에서 사르곤 구성원의 스킬 발동이 주변 8칸 아군 오퍼레이터에게 장비 효과를 공유한다. 대상은 사르곤으로 제한되지 않는다.
- V단계 이하 전투 효과 장비만 공유하고 VI단계는 제외한다. 보유 장비 자체를 옮기거나 추가하는 방식이 아니다.
- 공유 효과는 60초 후 제거된다. 같은 공유 장비 효과가 다시 적용되면 종료 시점을 갱신한다.
- 기존 사르곤 공격속도 중첩은 유지하고 기존 6명 효과의 공격력 중첩은 공유 효과로 대체한다.

관련 bands/bonds_core/items 테스트 122개 통과. 기존 테스트에는 실제 장비의 공격력 적용·60초 후 해제 검사가 포함된다. 현재 검토 범위에서 기능 오류를 발견하지 않아 전략 로직은 변경하지 않았다. 모든 장비 조합의 실전 장기 검증을 의미하지는 않는다.
