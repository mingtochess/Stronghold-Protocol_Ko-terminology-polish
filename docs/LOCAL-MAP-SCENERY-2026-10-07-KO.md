# 비활성 전장 구조물과 배경 장식

이전 수정은 모든 원본 지형에 삼각형 중심 기반 필터를 적용하여 경계의 장식과 배경 지형까지 잘렸다. 플랫폼은 기존 필터를 유지하고 장식은 별도 sceneryForArea로 처리한다.

장식 버킷의 연결된 메시 구성요소를 구하고 UV 이음매에 있는 동일 위치 정점을 합친다. 배경 범위를 벗어나거나 활성 전장에 걸친 구성요소는 전체를 유지한다. 비활성 전장 안의 독립 구성요소만 전체를 숨긴다. UV·광원·그림자 설정은 유지한다. 구조물이 배경과 연결되어 있으면 보존하는 보수적인 규칙이다.

검증: board3d 테스트 26개 통과. 사막맵 일반 시점에서 주변 지면이 복원되고 오른쪽 불필요한 독립 구조물이 숨겨진 것을 스크린샷으로 확인했다. 3개 맵의 브라우저 점검과 협력 전투 구역 확인을 수행한다.
