# 세 선발 오퍼레이터 SFX 검토 — v0.3.3h

2026-11-01. 중국 클라이언트 `audio_data`의 이벤트와 추출된 실제 ability graph를 대조했다. 근거 이벤트·원본 에셋 경로는 `content/custom/northern/sfx-events.json`, 재생성 코드는 `tools/northern-audio.mjs`에 보관한다. 파일 이름의 슬롯 문자만으로 스킬을 추측하지 않는다.

## 실제 원인

기존에는 대부분의 스킬 시전음만 들어 있었고, 별도의 `ON_ABILITY_ON` 발사음이나 원본 투사체 전용 명중음이 일부 빠져 있었다. 특히 토스카 강화탄/S3의 명중음이 일반 공격의 음원을 사용했고, 테리토리야의 공격 시작음과 발사음을 하나의 공격 이벤트로 처리했다. 탈룰라 S2의 강화 공격은 순간 스킬 종료 뒤에도 유지되는데 재생 경로가 `skillActive`만 보면 강화 명중음을 선택할 수 없었다.

수정은 세 오퍼레이터의 SFX 선택과 표현 이벤트에 한정한다. 공격 대상·피해량·SP·스킬 지속시간·모션의 타격 시점은 바꾸지 않았다. 모든 보완 음원은 다운로드 카탈로그에 들어가며 기존 로스터 대상의 제한된 디코딩 예열에서도 재귀적으로 수집된다.

## 검증

- 스킬 9종 및 공격 시작/발사/명중·강화 만료·표식·범위 공격 중복 재생을 포함한 전용 테스트 20개 통과.
- 관련 전투·SFX·렌더·리소스·버전 검사 269개 통과.
- 배포 전 릴리즈 라우팅 검사 68개 중 66개 통과, 2개 브라우저 전용 검사 건너뜀. 브라우저 검사 환경을 켜고 실제 Chromium으로 배포 전용 브라우저 검사 3개도 별도 통과했다.
- 실제 Chromium Web Audio에서 연결된 MP3 55개를 디코딩해 모두 비어 있지 않은 PCM 신호를 확인했다. 9개 스킬 활성화에서 원본 이벤트에 대응하는 13개 음원의 실제 `AudioBufferSourceNode.start()` 호출을 확인했고 페이지 예외는 없었다. 단순 메서드 대체 테스트와 구분한다.
- 기존 81개 전투 시나리오의 결정론적 결과도 수정 전과 동일했고, 기존 오퍼레이터 데이터의 변경은 0개다.
- 원본 56개 고유 클립 중 `b_char_boostclose`는 `ON_SKILL_SPECIAL_POINT.skchr_oxi_3`에만 연결된 수동 종료 계열 음원이다. 현재 자동 전투의 자연 종료에 임의로 재생하지 않았다.
- 음색·음량·피치가 원본 영상과 청감상 완전히 같다고 주장하지 않는다. 이번 검증 대상은 실제 이벤트에 맞는 음원 연결·다운로드·디코딩·재생 시작이다.

정규 버전 패치노트에는 이번에 처음 공개하는 세 선발 오퍼레이터 추가와 기존 공개 기능의 표시 수정만 기록한다. 공개 전 검토에서 보완한 항목은 별도 출시 버그 수정 목록으로 중복 기재하지 않는다.
