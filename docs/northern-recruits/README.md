# 북방 선발 오퍼레이터 추가

대상: 탈룰라(`char_4247_oxi`), 테리토리야(`char_4246_dminon`), 토스카(`char_4244_tocka`).

## 데이터와 선발

- 중국 클라이언트의 character/skill/range/module/audio 테이블과 검증된 `cn-operators-20261101-133603-390700` 추출물을 사용한다.
- 5·6단계 및 승급 전후의 12개 레코드를 생성한다. 상점 일반 등장 대신 기존 선발 슬롯을 이용한다.
- 기본 맹약은 우르수스다. 우르수스 확장이 비활성화되면 해당 게임 데이터에서 협동방어로 바뀌며 원본 목록은 변하지 않는다.
- 한국어 이름은 사용자 지정 표기를 사용한다. 한국어 설명은 원문 기반 번역이며, 영어·일본어는 정식 출시 번역으로 표방하지 않는다.

## 전투 구현

| 대상 | 추가한 처리 |
| --- | --- |
| 탈룰라 | 아츠 공격 및 연소 축적, 비공격 시간의 비호 축적과 공격 시 감소, 연소 폭발 대상의 이동 장판, S1 타일 공격·공포, S2 선제 피해 경감·반격·회복·개별 중첩, S3 방향별 이동 화염·과부하·반복 적중 감소 |
| 테리토리야 | 영역 내 지상 적 공격속도 감소·주기 피해, 퇴각 폭발, S1 최초 진입 둔화, S2 회피 무시 및 두 번째 사용 후 무한 지속, S3 전 영역 공격·피격에 따른 영역 확장·종료 시 정리 |
| 토스카 | 표식 발동 시 SP·회복, 표식 부여 후 강화 투사체·약화·지속 피해, S1 피격 반응 보호막·기절, S2 도착 지연이 있는 표식 투사체·자동 스킬 발동, S3 공격 강화·기절·공격력 감쇠 버프·SP 비율에 따른 표식 이전 |

수치는 레코드의 blackboard와 잠재·모듈 계산을 사용한다. 게임의 기존 자동 스킬 발동·피격·상태이상·투사체·격자 범위 처리에 연결한다.

## 애니메이션·시점·표시 규칙

- 실제 Front/Back Spine에서 애니메이션, 지속시간 및 타격 이벤트를 읽는다.
- 독립 시전인 탈룰라 S1/S2, 토스카 S1/S2는 공통 `skillImpactTiming`/`skillImpact` 경로로 피해·표식 발동을 지연한다. 시전 중 일반 공격도 기존 시전 잠금을 따른다.
- 탈룰라 S2는 실제 `Skill_2_Cambat` 클립을 연결한다. 최초 피해 경감은 시전 시작에 적용하고 반격은 타격 이벤트에서 처리한다.
- 지속 스킬은 기존 begin/loop/end 역할과 공격 재생 경로를 사용한다.
- 바닥 효과는 월드 지면 좌표를 사용한다. 이동 화염은 서버가 보낸 방향·속도를 사용하고 충돌한 개별 레인만 종료한다.
- 토스카의 부착 표식은 실제 보유 유닛을 따라가며 `depthOwner`와 `unitLayer`로 기존 유닛 깊이 정렬에 참여한다. 전역 최상위 레이어로 강제하지 않는다.
- 공식/간소 이펙트 경로를 모두 추가한다. 공식 SFX는 원본 이벤트별 뱅크를 연결하고 여러 화염 레인에서 동일 발사음을 중복 재생하지 않는다.

## 검증

- 새 전투·렌더·리소스 테스트: `node --test test/sim/northern-recruits.test.js test/render/northern-fx.test.js test/render/northern-assets.test.js`.
- 기존 81개 결정론적 시나리오(로스터 47, 맹약 23, 전장 6, 매치 5)의 현재 결과를 HEAD 작업본의 실제 결과와 비교했으며 동일했다. 기존 오퍼레이터 레코드 차이도 0개였다.
- 저장된 golden 스냅샷과는 기존부터 4개 그룹이 불일치한다. HEAD만 별도 추출한 작업본에서도 같은 실패를 확인했으며 기대 스냅샷을 덮어쓰지 않았다.
- Chromium에서 실제 전투 기록으로 간소/공식 모드를 촬영했다. 새 오퍼레이터 모델 3종은 모두 로드되었다. 미리보기 환경의 기존 적 모델·일부 공통 에셋 다운로드 실패는 별도 제한이며, 이 화면을 모든 스킬·기기에서의 완전 검증으로 해석하지 않는다.
- 실제 기기의 음향 청취 및 모든 방향·카메라·스킬 조합을 영상과 대조한 검증까지 완료했다고 주장하지 않는다.
