## 18개 항목별 반영 정도와 상세

반영 정도는 기능 수정과 해당 회귀 검증을 기준으로 한다. `완료`도 모든 기기·모든 스킬의 원작 영상과 픽셀 단위로 일치함을 뜻하지 않는다. 남은 검증·구현은 각 항목에 별도로 적었다.

- **관련 파일:** public/js/screens/game.js, public/js/render/projection.js, server/match/Match.js
- **검증:** 다양한 화면 크기의 대기석·머리 프레이밍 테스트와 원격 관전/참가자 메타데이터 테스트 통과.
- **남은 작업·범위:** 모바일·모든 해상도의 실제 UI 조합을 전부 촬영한 것은 아니다.
