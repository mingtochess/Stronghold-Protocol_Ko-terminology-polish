# 로컬 맹약·관전 정보 수정

- 맹약 구성원 목록은 선발 선택값이 true인 오퍼레이터만 포함한다. 보유 중인 오퍼레이터는 유지한다. 관전 대상의 선택 목록도 공개 상태로 전달하며 다른 사람의 선택을 자신의 목록에 섞지 않는다.
- 맹약 접기 버튼과 맹약 목록의 관전 대상 표식을 제거했다. 하단 관전 안내는 유지한다. 맹약 자체를 화면 중앙에 정렬한다.
- 이번 판 정보는 시작 전과 같은 matchInfoModel의 맹약별 밴 분류와 아이콘을 사용한다. 초상화는 흑백 처리하지 않는다.
- 현재 보고 있는 대상의 전략만 표시한다. 자신의 전장에서는 나의 전략을 표시하며 다른 전장을 볼 때에는 관전 대상의 전략으로 대체한다. 밴 분류 사이 여백을 줄였다.
- 창 밖 클릭 또는 키보드 포커스 이동으로 정보창을 닫는다. 창 내부와 상단 열기·닫기 버튼, 연결된 오퍼레이터·맹약 정보창은 예외다. 하위 정보창의 닫기 조작이 이번 판 정보창까지 닫지 않는다.
- CHAR_DAMAGE 누적 피해 안내 발신을 제거하고 구 서버의 같은 메시지도 클라이언트에서 숨긴다. BOSS_HIT 20%/50%/80% 기여율 안내는 유지한다.

검증: 관련 UI·클라이언트 전투·보스 기여율·버전 테스트 119개 통과. Chromium에서 1600px 화면의 맹약 중심이 800px임을 확인하고 현재 대상의 전략 1개, 밴 분류, 내부 클릭 유지·외부 클릭/포커스 닫힘을 검사했다.
