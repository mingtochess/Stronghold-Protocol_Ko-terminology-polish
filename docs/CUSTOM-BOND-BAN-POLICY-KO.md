# 커스텀 맹약 설정 변경

2026-10-09. 로컬 반영, 커밋·푸시하지 않음.

- 기존 ‘맹약 금지’를 ‘맹약 비활성화’로 변경했다. 맹약과 단일 핵심 맹약 오퍼레이터를 게임 콘텐츠에서 제외하는 기존 동작을 유지한다. 기존 설정·프리셋의 `disabledBonds`도 유지한다.
- 새 ‘맹약 금지’ 메뉴는 금지 단계의 추첨 정책을 설정한다. 핵심 맹약마다 무작위 / 항상 밴 / 밴 제외를 선택한다. 보조 맹약에는 이 설정을 제공하지 않는다.
- 항상 밴을 먼저 넣고 나머지를 기존 밴 개수에 맞춰 추첨한다. 지정 개수가 기존 밴 개수보다 많으면 지정한 맹약을 모두 밴한다. 밴 제외는 무작위 추첨에 포함되지 않는다. 전체 후보가 밴 제외라면 핵심 맹약의 무작위 밴은 생략한다.
- 항상 밴 적용 후 핵심 맹약이 최소 5개 남아야 한다. 난이도에서 활성화되지 않은 맹약이나 비활성화된 맹약은 밴 정책으로 지정할 수 없다. 같은 맹약에 항상 밴·밴 제외를 동시에 적용하지 않는다.
- UI에서 맹약을 비활성화하면 그 맹약의 밴 정책을 해제한다. 항상 밴·밴 제외를 지정하면 해당 맹약의 콘텐츠 비활성화를 해제한다.
- 새 정책도 마지막 설정과 커스텀 프리셋에 저장한다. 정책을 설정해도 해당 맹약을 데이터 테이블에서 삭제하지 않으며 실제 금지 단계 결과에 반영한다.
- 상점 초상화는 기존보다 0.05rem 올렸다. 선호 설정의 이미지도 위로 이동하여 얼굴 아래쪽이 덜 잘리게 했다.

검증: 관련 서버/대기실/프리셋/추첨 테스트 97개 통과. 여러 시드의 강제 밴·밴 제외, 실제 Match 결과, 기존 비활성화 설정 호환, 최소 구성 제한, 정책 전환을 확인했다. 브라우저에서 데스크톱·모바일 표시, 프리셋 저장 및 적용 값, 수평 넘침 없음을 확인했다.
