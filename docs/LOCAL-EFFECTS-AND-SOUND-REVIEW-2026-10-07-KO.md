## 사운드 이벤트 점검과 수정

| 이벤트 | 적용 시점/선택 방식 |
|---|---|
| 공격 시작 (`atkStart`) | 선딜레이 시작에 공격자 자신의 시작음 재생. 같은 공격의 `atk`에서 반복하지 않음 |
| 공격 발사 (`atk`) | 선딜레이 이벤트가 없는 공격은 이 이벤트에서 시작음 재생 |
| 실제 피해 (`dmg`) | 서버가 보낸 실제 피해 출처를 사용해 공격자의 피격음 선택. 다른 공격자가 같은 대상을 먼저 겨냥해도 영향받지 않음 |
| 스킬 시작 (`skill:true`) | 선택한 스킬 번호의 공식 `ON_SKILL_START` 은행 사용 |
| 스킬 종료 (`skill:false`) | 선택한 스킬 번호의 공식 `ON_SKILL_FINISH` 은행이 있으면 사용 |
| 배치/사망 | 기존 유닛별 공식 음원, 없는 경우 유닛 종류별 기본 음원 |
| 제국 드론 | 기존 조준 경고음 길이 제한·낙하 시작 시 경고 종료·충돌 시 폭발음 연결 유지 |

사운드 이벤트는 화면에 표시되는 보간 이벤트와 함께 처리합니다. 실제 피해 출처가 없는 HP 소실/지속 처리에는 이전 공격자의 피격음을 임의로 붙이지 않습니다. 예전 서버의 메타데이터 없는 패킷에는 기존 제한 시간 방식이 남아 있습니다.

공식 audio_data와 로컬 오퍼레이터의 고유 스킬 334개를 대조했습니다.

- 시작 음원 은행 있음: **212개**. 은행이 없는 **122개**에는 다른 스킬 소리를 임의로 붙이지 않습니다.
- 종료 음원 은행 있음: **6개**. 이번에 종료 이벤트에 연결하고 캐시 다운로드 목록에 넣었습니다.
- `ON_SKILL_SPECIAL_POINT` 은행 있음: **23개**. 해당 특수 지점은 개별 스킬의 타임라인을 대조해야 합니다. 이번 공통 변경으로 모두 정확히 연결했다고 주장하지 않습니다.
- 스킬 모드에 사용하는 기존 공격/피격 파일이 일반 공격에 잘못 쓰이는 방지를 유지하고, 스킬 사용 중에는 그 파일 재생을 허용합니다. 모드별 복수 공격 은행의 모든 세부 매핑까지 새로 구축한 것은 아닙니다.
