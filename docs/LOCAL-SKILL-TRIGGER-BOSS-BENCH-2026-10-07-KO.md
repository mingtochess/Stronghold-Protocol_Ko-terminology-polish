# 스킬 범위 발동과 보스 관전 대기석 점검

## 스킬 발동

기존 DEFAULT 발동 판정은 와일드메인 2·첸 더 던스트릭 3·아스트젠 3스킬만 ID 목록으로 예외 처리했다. 불피스폴리아 3스킬은 활성화 중의 확장 공격 범위가 구현돼 있어도 이 목록에 없어, 일반 공격 가능 여부를 먼저 기다렸다.

수정: 지속·탄약·토글 스킬의 실제 targeting.rangeGrid / rangeExtend와 스킬 능력치의 rangeExtend를 읽고, 기본 범위 밖으로 확장되는 경우 독립적으로 발동 조건을 검사한다. 독립 즉발 스킬의 명시된 효과 범위도 검사한다. 활성화 이후 사거리만 바꾸는 것이 아니라 활성화 이전의 발동 판정에 적용한다. 표적의 공중·은신 등 선택 가능 여부는 유지한다. 다음 공격 강화·충전 대기형과 치유형의 발동 조건은 유지한다.

검증: 생산용 카탈로그 736개 스킬 설정 × 네 방향 2,944건을 훑었다. 전장 안에서 기본 범위 밖에 적을 놓을 수 있는 362개 사례에서 발동했고, 콘텐츠 오류는 0건이다. 불피스폴리아 3, 실버애쉬 3, 모스티마 3, 이네스 2, 수르트 2/3, 기타 선발·우르수스 설정을 포함한다. 전체 목록은 SKILL-PROSPECTIVE-RANGE-AUDIT-2026-10-07.json에 기록한다. 이번 자동 대조는 기본 모듈 기준이며 원작의 모든 수동 스킬 사용 판단까지 일치함을 보증하는 것은 아니다.

## 관전 대기석

보스전 휴식 관전 m.field에서 전장 배치는 보스 좌표로 변환했지만 대기석·임시 대기석은 일반 맵 행 7/8을 보냈다. 보스 맵에서 행이 위쪽으로 어긋나게 표시되는 경로다. 같은 fieldTile 변환을 적용해 대기석 행 0, 임시 대기석 행 1을 사용하며 오른쪽 플레이어의 열과 방향도 반전한다. 반복 갱신 5회에서 위치가 유지되는 테스트를 추가했다.

이전에 수정한 관전 스킨 전달도 유지한다. 대기석/임시 대기석만 가진 플레이어의 스킨 설정 변경도 관전 갱신에 반영되도록 변경 감지에 해당 설정을 포함했다.

관련 자동 테스트 108개 통과. 로컬에만 반영하며 커밋·푸시하지 않음.
