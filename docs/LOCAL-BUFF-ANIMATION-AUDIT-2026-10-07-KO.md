# 발동 동작·지속 자세와 일반 공격 매핑 점검

운영 카탈로그의 오퍼레이터 135명, 선택 가능한 스킬 334개를 조사했다. 스파인 역할, OnAttack 이벤트, 클립 시간과 스킬 설명을 대조했다. 짧은 클립이라는 이유만으로 공격을 변경하지 않고, 일반 공격을 유지하는 능력치·반격 스킬을 명시적으로 분류했다.

## 검증과 범위

서버의 타격 시점 생성도 동일한 명시적 분류를 사용하며, 운영용 데이터에 다시 생성한 타격 정보를 포함했다. 테스트는 앞/뒤 모델과 스킨 매핑, 일반 공격 시작·타격·종료, 기존 지속 채널과 운영용 데이터 일치를 확인한다.

이 점검은 발동·지속 동작을 일반 공격에 잘못 사용하는 문제에 대한 점검이다. 모든 스킬의 모든 모션이 원작과 완전히 동일하다는 보증은 아니다. 변경은 효과 설명과 모션 역할이 명확한 사례에 한정했다.
