# 원본 선발 오퍼레이터 통합 시험

- 작업 폴더: `/workspace/Stronghold-Protocol_Recruits_Test`
- 브랜치: `local/upstream-recruits-test`
- 기준: 현재 로컬 변경 사항과 원본 `3eced7b` (0.2.1).
- 원래 작업 폴더의 코드에는 적용하지 않았으며 커밋·푸시하지 않았다.

## 통합 범위

원본 소유 오퍼레이터 71명과 원형·예비 오퍼레이터 15명을 가져왔다. 기존 토가와 사키코를 포함해 목록은 87명이다. 기존의 선발 식별자, 한국어 설정 페이지, 전략 선택 중 수정, 선발 표시, 맹약 금지 처리를 유지했다. 원형은 원본처럼 단계별 선발이 가능하고 지정 스킬·모듈을 고정한다. 모드 전용 모듈은 선택에서 제외한다.

선발 재고는 플레이어별로 독립시키고 일반 오퍼레이터의 재고는 공유한다. 설정 변경 시 실제 모집·보상 자격과 재고를 다시 동기화한다. 소환물의 선택 모듈별 배치 수, 상태와 재배치 처리를 연결했다. 한국어 화면 텍스트와 원본 규칙 파싱용 텍스트를 분리해 번역이 전투 수치에 영향을 주지 않도록 했다.

## 기존 구현과 비교한 결정

| 오퍼레이터 | 결정과 이유 |
| --- | --- |
| 위셔델 | 원본의 과열 전환, 무작위 연속 사격, 여진·그림자 처리가 더 상세하여 채택했다. 기존 연타별 장비 발동과 직접 회복 금지 처리는 유지했다. |
| 나란투야 | 원본의 왕복 투사체, 도탄, 능력치 흡수 처리를 채택했다. 번역된 모듈 설명 때문에 수치 인식이 실패하지 않도록 보완했다. |
| 첸 더 던스트릭 | 원본의 진행하는 파동과 지속 참격을 채택했다. 공격 범위 밖의 스킬 범위에 있는 적과 공중 적에 대한 발동 조건은 기존 수정과 결합했다. |
| 아스카론 | 원본의 회피·스킬 강화와 중첩 지속 피해 처리를 채택했다. 지속 피해에 장비가 반응하는 기존 동작과 중첩 감속을 유지했다. |
| 토가와 사키코 | 원본에 대응 구현이 없어 기존 음표 생성·추적·비눗방울 투사체를 유지했다. |

## 검증

- 원본 71명 동작 검증: 690개 통과.
- 공격 시점, 확장 스킬 범위, 직군, 배치, SP/과열, 소환물, 회복 대상, 연타 장비, 개인 재고 및 금지 관련 회귀 검사: 132개 통과.
- 기존 선발·사키코 및 금지·개인 재고 검사: 18개 통과.
- 광범위 회귀 검사는 기존 작업 폴더와 함께 실행해 기존 실패를 비교했다. 개인 재고 도입에 따라 공유 풀을 강제로 조작하던 테스트는 실제 플레이어 풀을 조작하도록 수정했다. 기존 데이터와 캐시를 가정하는 일부 테스트는 원래 로컬에서도 실패하므로 전체 테스트가 통과한다고 주장하지 않는다.
- 실제 Chrome에서 한국어 목록 87명, 새 오퍼레이터 초상화 로딩, 5·6단계 선택 및 서버 동기화를 확인했다. 화면: `selection.png`.

## 추가 밸런스·모바일 수정

- 모바일 상점 자금 카드의 접기 버튼이 넘치지 않도록 화면 배율에 맞춰 크기를 조정.
- 우쿠시크 2단계·비헌터 3단계로 교체. 우쿠시크 중첩 획득 +3, 비헌터 +5 (기존 정예 배율 유지: +6/+10).
- 보타니의 신속 맹약과 획득 중첩을 기적으로 변경.
- 사키코 음표 비눗방울의 반지름을 기존의 50%로 축소.
- 6단계 장비 「황제의 은총」 추가. 통합전략 `rogue_1_relic_a14` 아이콘 사용. 최대 HP +30%, 공격 속도 +30. 우르수스 착용자는 공격 대상에게 자신의 최대 HP 5%의 트루 대미지. 우르수스 곡도 동시 장착 시 같은 플레이어의 제국 드론 공격 속도 +1, 전투당 합계 최대 +100. 실제 연타는 각각 적용하며 장비 추가 피해가 다시 장비를 발동시키지 않음. 일반·정예 장비 모두 지정된 수치를 적용.
- 아군 우르수스 드론 모델을 기본 85%로 축소. 맹약 중첩당 기본 모델 크기의 0.5%씩 증가. 이 효과는 설명에 표시하지 않고 전투·관전 스냅샷으로 전달하며, 공격 판정·범위·체력에는 영향을 주지 않음.
- 관련 전투·보간·장비·사키코 검사 68개 통과. 맹약 획득·승급 처리 검사 2개 통과.
- 모바일 실제 상점 컴포넌트: `shop-844.png`, `shop-740.png`, `shop-1920.png`. 접기 버튼의 카드 내 배치와 클릭 동작 검증.
