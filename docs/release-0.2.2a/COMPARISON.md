# 0.2.2a 실제 플레이 변경 비교

기준: 커스텀판 0.2.1b와 원본 0.2.2(62eb113). 원본의 새 규칙을 기존 커스텀 전투·렌더링에 이식했다. 아래에서 **통합**은 원본 기능을 커스텀 구조에 결합한 것, **유지**는 요청한 기존 동작을 유지한 것, **추가**는 이 포크의 변경이다. 파일을 가져왔다는 이유만으로 원본의 모든 UI를 그대로 적용했다고 간주하지 않는다.

## 이번 포크의 변경

## 충돌 시 유지·제외한 것

- 기존 우르수스·헬라그·비헌터 등 커스텀 맹약·티어·특질과 원본 신규 규칙을 함께 사용한다. 같은 슬롯의 선발은 원본 실제 스킬 키트로 통합하고 로컬 ID·프리셋을 유지했다.
- 공격점·피격·스킬 범위·검기는 실제 월드 위치를 따른다. 원본 코드의 화면 좌표 처리로 되돌리지 않았다.
- 원본 맵 모델·장식·물·침수 지상 고도·기존 밝기 대비·진영별 카메라와 관전 대기석 스킨을 유지했다.
- 원본 HP/SP 기능을 추가하면서 포크의 검은 HP 프레임·흰색 보호막·아군 저HP 색상 고정·정보 창 탄약 표시를 유지했다.
- 선호 프리셋·선발 강조 위치·아이콘 접기·현재 자금 아래 텍스트 접기·커스텀 확장 프리셋·금지/보호/비활성화 정책을 유지했다.
- 타수 적은 요청대로 난이도 HP 배율로 타수가 늘지 않는다. 원본 0.2.1에서 들어간 타수 배율 정책으로 되돌리지 않았다.
- 공격 효과음은 요청한 롤백 타이밍을 유지한다. 공격 선딜에 다시 효과음을 붙이지 않았고, 배치 직후 누락된 스킬 음성 보충만 결합했다.
- 원본의 중국어 기본 음성·별도 소유 여부 편집과 DIY 슬롯 페이지를 중복 도입하지 않았다. 한국어/일본어 선택과 안정적인 개인 선발 페이지를 사용한다.
- 원본의 표형 설정 페이지 전체 교체, AI 구매 점수 변경, 별도 권한 페이지·방화벽 스크립트, 배경 음악·보드 스타일 신규 설정은 도입하지 않았다.
- 원본 AGENTS/CLAUDE 지침 파일은 포크 설정 위에 덮어쓰지 않았다. GitHub 이슈 템플릿은 반영했다.

## 검증

선발 원본 규칙 검증 691개 통과. 전투·잠재·UI 회귀 139개, 포탈·수학·AI 등 추가 검증 58개, FX·선발 통합 223개 검사 통과. 에셋·오디오 검사는 98개 통과·원격 의존 검사 9개 제외. 소스 954개 문법 검사와 상대 모듈 import/export 검사 통과. 실제 Chromium에서 준비 전장 캔버스와 선발 목록 80명·설정 동기화 확인. 구매·배치·전투 시작 후 실행·시뮬레이션 오류 없음 확인. 패치노트는 1280/740/390px에서 한 줄 유지·창 너비 준수 확인.
