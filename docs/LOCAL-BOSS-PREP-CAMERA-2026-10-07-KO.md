# 보스전 휴식 기간 시점 전환

보스전·히든 보스전의 휴식 기간에 같은 전장에 배정된 두 플레이어를 하단 좌우 화살표로 전환한다. 휴식 배치 정보는 한 플레이어별로 전달되므로 단순한 빈 반대편 카메라 이동 대신 기존 g.watch로 상대 배치·대기석·보스 미리보기를 받는다. 오른쪽 플레이어의 prepSide를 서버가 전달하여 오른쪽 준비 시점으로 이동한다. 본인으로 돌아오면 기존 편집·상점 동작을 사용하며 관전 중에는 읽기 전용이다. 한 명만 배정된 전장에는 화살표가 없다. 전투 중의 좌측·전체·우측 전환은 유지한다.

상점 버튼 순서는 접기 → 동결 → 새로고침이며 기존 자금 옆 접기 버튼도 유지한다.

검증: 준비 시간 관전·맹약 UI 테스트 37개 통과, 상점 실제 브라우저에서 양쪽 접기 버튼 클릭을 확인했다. 로컬만 적용.
