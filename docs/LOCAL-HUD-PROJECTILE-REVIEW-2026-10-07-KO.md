- 안내 메시지를 맹약 목록 아래로 이동하고 목록을 조금 올렸습니다.
- 맹약 활성화 단계 외곽선 두께와 원판 사이 간격, 단계 사이 간격을 늘렸습니다.
- 실제 배치 인원이 없는 맹약은 중첩·가상 인원 보너스가 있어도 숨깁니다. 대기석까지 세는 맹약은 해당 집계 방식을 유지합니다. 실제 맹약 활성화 판정은 변경하지 않았습니다.
- 목록은 10개 너비로 제한하고 나머지는 가로 스크롤로 확인합니다. 기존 개수 제한으로 잘리던 항목도 표시합니다.
- 버튼 클릭 후 포커스를 해제합니다. 클릭으로 채팅을 열면 입력창에 자동 포커스를 주지 않고, PC의 Enter로 열면 입력창에 포커스를 줍니다.
- 루프 슈터 부메랑은 일반 투사체 확대 배율에서 제외했습니다. 원본 무기 이미지도 별도 크기로 축소했습니다.
- 투사체 본체를 일반 합성·불투명 중심 이미지로 변경했습니다. 꼬리·잔상과 도착 후 소멸 효과는 유지합니다. 전용 원본 텍스처의 투명 여백은 보존합니다.
