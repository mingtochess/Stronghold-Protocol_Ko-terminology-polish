# 원본 0.1.4 통합 — 로컬 0.1.4a

2026-10-06. 원본 `sganggs/Stronghold-Protocol`의 `v0.1.4` (`9f93096`)를 기존 로컬 구현과 통합했다. 기존에 검토한 `a0a5419` 이후 변경 147개 파일을 대조했다. 커밋·푸시·운영 배포는 하지 않았다.

## 다운로드와 맵

- 최초 공개 미러 다운로드 안내와 동의는 유지한다. 동의하면 먼저 게임에 진입하고 부족한 리소스를 백그라운드에서 받는다.
- 다음 방문에는 동의를 다시 요구하지 않고 실패·누락된 파일을 이어 받는다. 기존 버전 캐시도 재사용한다. 동일 파일의 화면 요청과 백그라운드 요청은 하나의 다운로드를 공유한다.
- 화면에서 먼저 필요한 파일은 서비스 워커가 즉시 요청한다. Spine atlas는 PNG 크기와 PMA를 정규화한 후 캐시에 저장한다.
- 원본 맵이 준비되지 않았다면 기존 단순 맵을 표시한다. 맵 로딩을 화면 초기화에서 기다리지 않는다. 다운로드가 완료된 현재 전장만 원본 맵으로 교체한다.
- 원본 맵 압축 파일은 동시에 두 개씩 미리 받고, 디코딩한 장면은 최근 두 개만 유지한다.
- 이전에 수정한 사막 타일 lightmap UV, 실제 그림자, 일반/연합/보스 전장 영역 필터링을 유지한다.

## 원본 변경과 겹치는 구현의 선택

| 분야 | 적용한 방식과 이유 |
| --- | --- |
| 에기르 포식 | 원본의 최종 공격력 가산 `atkFinal`을 채택. 중복 비율 증폭을 방지한다. 기존 normal→unite 포식 완료·공격력·저지 수·부활 예산 전달은 유지한다. 이전 `atkFlat` 전달값도 읽을 수 있다. |
| 5에기르 부활 | 처음 쓰러진 적격 구성원 세 명이 공동 예산을 사용한다. 구성원 자신의 생존 효과와 중복 부활을 구분한다. 다른 플레이어 포식에 앞서 대상 소유자의 부활 훅이 등록되도록 개선했다. |
| 티티 2스킬 | 원본의 반복 수면 진입 특질 계산을 적용한다. 기존 아군 수면 해제와 무관하게 지속되는 장판을 유지한다. 상태 저항·프레임 경계 때문에 순간적으로 수면이 풀리지 않도록 갱신 여유 시간을 준다. |
| 수면·강제 이동 | 원본 수면 저지 해제를 적용하되 기존 강제 이동 중 저지 불가 조건을 함께 유지한다. |
| 배치 후 지속 스킬 | 정상적인 스킬 시작·종료 생명주기를 적용한다. 명시된 배치 한정 스킬의 사거리·타격 상태·피해 유형도 그 지속시간을 따른다. 기존 배치 애니메이션 종료 후 행동 시작을 유지한다. |
| 공격·스킬 애니메이션 | 원본의 단발 스킬 클립 개선과 기존 타격 시점·재대상 지정·공격 후 모션 유지·지속 채널 스킬을 결합한다. 우타게 2스킬에 1스킬 모션을 쓰지 않는 기존 수정도 유지한다. |
| 음성 | 기존 KR/JP 설정, 기본 볼륨 60, 즉시 교체 재생, 직접 구매한 오퍼레이터 클릭 발성, 무작위 시작 발성, 승리 음성 미사용을 유지한다. 원본의 오래된 음성 콜백이 새 음성 채널을 해제하는 문제만 보강한다. |
| BGM | 이미 구현한 라운드별 곡 선택·휴식곡·인트로/루프 연속 재생을 유지하고 원본 누출 경고음을 추가한다. |
| 관전 | 원본 대기석·장비·효과 전달과 기존 좁은 카메라·보스·스킨 전달을 함께 유지한다. |
| 지형·직군 | 특성 문구에 따른 고지대 배치 규칙, 수면 저지 해제, 무사/수확자 스킬 타격 회복, 주술 메딕 피해별 회복 등 원본 수정을 반영한다. |
| 커스텀·설정 | 우르수스, 선발 오퍼레이터, 커스텀 확장, 한국어 UI, 채팅, 기존 스킬·스킨 저장 구조를 유지한다. 로딩 또는 버전 변경 시 저장값을 초기화하는 코드를 추가하지 않았다. |
| 난이도·보스 | 기존 사용자 지정 인원 배율·솔로 보스 보정 제거·일반 적 모드 보정을 유지한다. 원본으로 되돌리지 않는다. |

원본과 로컬에 같은 기능이 있으면 중복 훅과 선언을 제거했다. 원본의 상세창 열기/결과 시 음성은 사용자 요구와 달라 채택하지 않았다. 원본 테스트의 기대값도 이러한 의도된 차이에 맞췄다.
