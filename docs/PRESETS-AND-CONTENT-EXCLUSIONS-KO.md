# 프리셋 필터와 콘텐츠 금지

로컬 적용. 커밋·푸시·운영 배포는 하지 않았다.

## 프리셋 화면

프리셋 목록과 편집 영역을 분리했다. PC에서는 왼쪽 목록/오른쪽 편집, 모바일에서는 위쪽 목록/아래쪽 편집으로 구성한다. 기존 모달·버튼·탭·테두리·민트 선택 강조를 유지했다. 이름 검색, 맹약 필터, 1~6단계 필터를 동시에 적용하며 필터 변경은 프리셋 내용에 영향을 주지 않는다.

[TFT Team Planner 설명](https://wiki.leagueoflegends.com/en-us/TFT:Team_Planner)을 확인했지만 검색에서 신뢰할 수 있는 현재 UI 스크린샷은 확보하지 못했다. 스크린샷을 직접 대조했다고 주장하지 않으며, 요청한 별도 프리셋 영역과 필터 구성을 기존 UI로 구현했다.

## 금지 규칙

커스텀 확장 설정에 핵심 맹약/맵/보스/전략 금지 탭을 추가했다. 보조 맹약은 금지할 수 없다. 방장 설정이 모든 참가자와 전투 시뮬레이션에 적용된다.

- 핵심 맹약이 하나인 오퍼레이터는 소속 핵심 맹약이 금지되면 제거한다. 보조 맹약이 남더라도 등장하지 않는다.
- 핵심 맹약이 둘이면 금지되지 않은 핵심 맹약을 남긴다. 둘 다 금지되면 제거한다.
- 금지한 맹약의 전용 장비와 관련 전략도 제거한다. 금지된 요소는 상점/보상/전략 선택/맵 및 보스 추첨에 들어가지 않고 클라이언트의 이번 판 데이터 조회에서도 제거된다.
- 오퍼레이터 구성용 원본 목록과 저장된 스킬·모듈·스킨은 유지한다. 현재 판에서 제외된 오퍼레이터의 설정만 적용을 건너뛴다.
- 우르수스를 활성화한 상태에서도 우르수스 맹약을 금지하면 우르수스 확장은 게임과 채팅에서 비활성화된다.

## 최소 구성

| 요소 | 최소 |
| --- | --- |
| 활성 핵심 맹약 | 5개. 무작위 밴 후에도 5개가 남도록 무작위 밴 수를 줄인다. |
| 맵 | 현재 난이도에서 실제 추첨 가능한 맵 1개 |
| 일반 보스 | 현재 난이도에서 추첨 가능한 보스 1개 |
| 히든 보스 | 히든 라운드가 있는 난이도에서 추첨 가능한 보스 1개 |
| 전략 | 솔로 1개 / 협동 4개 (4명이 서로 다른 전략을 고를 수 있어야 함) |

설정 창은 부족한 요소를 표시하고 적용을 막는다. 서버는 방 생성·설정 적용·난이도 변경·게임 시작에서도 다시 검증한다. 잘못된 설정으로 기존 방을 떠나거나 저장 설정이 변경되지 않도록 검사 순서를 유지한다.

## 검증

관련 회귀 검사 106개 통과. Chromium에서 PC/모바일 프리셋·금지 설정 창 오류 없음. 우르수스/6단계 필터에 헬라그·로사만 표시되는 것, 금지 요소가 클라이언트 조회에 없는 것, 최소 핵심 맹약 수를 어기면 적용 버튼이 비활성화되는 것을 확인했다. JavaScript 구문 검사와 git diff --check 통과.

최종 UI 구성의 대안 비교와 선정 이유는 [구성 화면 비교](CONFIGURATION-UI-LAYOUT-REVIEW-KO.md)를 참고한다.
