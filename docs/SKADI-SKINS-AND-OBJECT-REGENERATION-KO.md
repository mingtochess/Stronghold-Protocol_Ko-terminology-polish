# 스카디 스킨 및 아군 오브젝트 지속 회복

- 스카디 더 커럽팅 하트의 서블리메이션·레드 카운테스 전투 모델은 `Front/Back`이 아닌 `Spine` 폴더에 있다. 스킨 생성기가 단일 모델 경로도 지원하도록 수정했다. 같은 구조의 다른 스킨도 복구된다.
- 직접 힐과 지속 회복의 대상 선정을 분리했다. 음유시인·스카디/시본·퍼퓨머·안젤리나·스즈란·블레미샤인·틴맨의 지속 회복에 장치형 아군 오브젝트를 포함했다. 기존 고립 대상 제외 조건은 유지했다.
- 장치형 오브젝트의 직접 힐은 회복 계산에서도 차단한다. 회복 불가 오퍼레이터와 위셔델 소환물은 기존처럼 지속 회복만 받을 수 있다.
- 스카디 3스킬은 특성이 피해 효과로 바뀌므로 지속 회복을 제공하지 않는다.

검증: 실제 스카디 2스킬의 장치·위셔델 소환물 회복과 직접 힐 차단을 포함한 관련 테스트 153개 통과. 스킨 두 종의 전투 모델·텍스처·초상화 리소스 10개 모두 로컬 서버 HTTP 200 확인.

기존 음유시인 테스트는 지속 회복의 최초 갱신 이전부터 시간을 측정해 오차가 있었다. 범위 버프 갱신 후 3초 동안의 실제 회복량을 측정하도록 수정했다.
