# 0.2.1a 로컬 UI·전투 검증

커밋·푸시·운영 배포 없이 로컬에 적용했다. 기존 스킬·스킨 설정 저장 구조는 유지한다.

## UI

- 오퍼레이터 구성 화면의 선호 프리셋 버튼은 탭 행 오른쪽에서 일반 화면 버튼 스타일을 사용한다. 모바일 상단 가져오기·내보내기 도구는 제목 아래에 분리한다.
- 상점 도구는 접기·선호 아이콘을 같은 행에 배치하고, 현재 자금 아래의 텍스트 `접기` 버튼도 유지한다. 두 버튼은 같은 동작을 호출한다.
- 선발은 선호 목록에서 제외하고 민트 테두리와 `선발` 표시로 구분한다. 선호 카드는 하늘색 발광 테두리와 별표를 표시한다.
- 확장 설정은 맹약 아이콘, 정사각형 전략 초상화, 적 초상화, 원본 맵 에셋을 직접 촬영한 큰 사진 카드를 사용한다. 공통 금지 안내는 상단에 한 번만 표시한다. 맵 난이도는 `stages.modes`를 기준으로 중복 없이 표시한다.
- 확장 프리셋의 저장·불러오기·삭제를 지원한다. 불러오기는 초안만 바꾸며 `적용` 전에는 방 설정을 바꾸지 않는다.
- 상단 단계 문구를 중앙 정렬한다. 보스전 휴식 기간의 관전 대상 조작은 자신의 상점이 접혔을 때 표시한다.
- 대기실 채팅은 대기실 화면 안으로 옮겨 다른 대화상자보다 앞에 표시되지 않도록 한다.

## 전투

- 최초 배치는 왼쪽 열부터 위→아래 순서다. A B C D / E F G H라면 A E B F C G D H 순서다. 기존 0.2초 간격은 유지한다.
- 아군·적 제국 드론 공격 범위를 기존 두께와 더 불투명한 팀별 윤곽선으로 표시한다. 적 드론에도 범위 메타데이터를 전달한다. 폭격 조준 표시는 실제 피해 반경을 유지한다.
- 미스틱 캐스터의 저장 에너지 변화와 개수를 스냅샷·이벤트로 전달하고 실제 `Attack_Charge` 모션을 사용한다. 지속 스킬 모션은 충전 모션으로 덮어쓰지 않는다.
- 텍사스 2스킬은 범위 내 지상·공중 적에게 두 번 피해를 준다. 기존 같은 프레임의 두 타격을 분리하고 첫 타격 지연을 줄였다. PRTS로 두 타격과 대공을 확인했으나 추출 모델에는 타격 이벤트가 없다. 현재 1초/1프레임 간격은 연출 조정값이며 원작의 정확한 프레임 재현으로 단정하지 않는다.
- 포트리스가 자신이 저지한 적을 공격하면 일반 공격의 광역 피해를 제거한다. 에쉬락 `Attack02`, 혼 `Attack_B` 및 스킬 `B` 모션을 사용하고 해당 Spine 타격 시간도 연결한다. 혼 2스킬의 근접 광역 예외는 유지한다.
- 은신은 모델 불투명도를 유지하고 어두운 모델 색과 실제 구름 텍스처를 표시한다. 구름의 농담·크기·농도를 보강했다. 피격 붉은 표시는 약 0.167초→0.222초로 늘렸다.

### 추가 검증: 상점 배지·탄약·총 계열 보스·침수 경로

- 상점 별표와 선발 표시는 가격 배지와 동일한 상단 위치로 정렬했습니다. 보유 수 표시는 겹치지 않도록 아래로 이동했습니다. 브라우저 실측 상단 좌표 차이 0px, 런타임 오류 없음.
- 정보창은 스냅샷의 `ammo` 정보를 받지 않아 탄약 구획이 누락되었습니다. 표시 중인 전장의 스냅샷에서 탄약 수를 전달하고 잔여 탄약·구획을 표시합니다. 실제 컴포넌트에서 `탄약 7 / 10` 및 구획 표시를 확인했습니다. 스크린샷: `detail-ammo-review.png`.
- 총기사 제보는 현재 적 목록의 `가상적: 총`으로 해석해 점검했습니다. PRTS [假想敌：铳](https://prts.wiki/w/假想敌：铳): 기본 공격 속도 0, 하한 20, 동일 대상 공격 직전 +80씩 최대 5중첩, 대상 변경 시에도 최소 1중첩. 기존 코드는 첫 공격을 0중첩으로 처리하고 공격 후 갱신했습니다. 공격 직전 적용하고 이미 경과한 시간을 제외하여 다음 공격 대기 시간을 갱신했습니다. 일반/히든 각각 80→160→240 및 공격 간격 5.625초→2.8125초를 회귀 테스트로 검증했습니다. 다른 적을 지칭한 제보라면 별도 확인이 필요합니다.
- 침수 보스 전장에서 저지 가능 타일 선호 보정이 상단 경로를 벗어나게 하는 차이를 확인했습니다. 침수 보스 전장만 원본 SPFA 경로를 사용합니다. 두 침수 맵·양쪽 기지·두 출구씩 8개 경로를 검증했습니다. 일반 전장에 적용한 기존 경로 보정은 유지합니다.
- 관련 UI 테스트 26개 및 경로/총 계열 보스 테스트 9개 통과. 커밋·푸시·운영 반영 없음.

### 배포 후 맵 이미지·선발 화면 제보 수정

### 휴식 위치·잔류 효과·치료 불가 대상 제보

- 휴식 위치 갱신 시 같은 목적지의 진행 중 보간을 다시 시작하지 않도록 수정했습니다. 편집 가능한 본인 전장에서 읽기 전용 관전으로 바뀌거나 전투에서 휴식으로 전환할 때 드래그/배치 대기 상태를 정리합니다.
- 한 기물의 모델 업데이트 오류가 다른 기물의 업데이트를 중단하지 않도록 분리했습니다. 효과 수명 갱신은 프레임 정리 단계에서 실행하고 효과 업데이트 자체가 실패하면 잔류 효과를 정리합니다. 제보 당시 콘솔 오류는 확보하지 못했으므로 최초 예외를 발생시킨 모델/에셋은 확정하지 않았습니다.
- 직접 회복의 자기 회복 판정이 `opts.self`만으로 우회되던 경로를 수정했습니다. 실제 source/target을 비교하며, 주체가 없는 시스템 회복만 기존 명시적 self 설정을 허용합니다. 유 3스킬 재능의 최대 HP 기반 지속 회복은 regen으로 구분하여 무사·리퍼·저거너트와 같은 직접 치료 불가 대상에게도 적용합니다.
- 소환물 데이터의 `noHeal`을 공통 초기화에서 반영하고 위셔델의 레버넌트의 그림자에 설정했습니다. 직접 회복과 의료 타겟 선택에서 제외하며 음유시인 HP 회복 속도 효과는 유지합니다. 이미 치료 불가/고립 특성이 지정된 다른 소환물의 판정은 유지했습니다.
- 공식 KR 테이블에서 소환물의 이름·특성·스킬을 번역하도록 선발 데이터 생성기를 수정하고 운영용 토큰 데이터에도 반영했습니다.
- 치료 판정·음유시인·소환물·UnitView·승급 효과 관련 테스트 56개 통과. 더 넓은 선발 테스트의 나란투야/금지 맹약 선발 풀 2개 실패는 이번 변경 범위와 분리해서 확인할 사항입니다. 커밋/푸시하지 않았습니다.

### 선발 포함 렌더링의 실제 원인 확인

위셔델을 전장에 넣은 브라우저 테스트에서 `[render] unit frame failed p:1 ReferenceError: P is not defined`를 재현했습니다. `UnitView._updateHud`의 선발 텍스트 생성이 함수 범위에 없는 `P`를 참조했습니다. 선발이 전장/대기석에 있을 때 오류가 반복되고, 기존 공통 프레임에서는 뒤쪽 기물 업데이트와 이펙트 수명 처리까지 중단될 수 있었습니다. `this.P.Text`로 수정했습니다. 앞선 최초 오류 미확정 기록을 이 결과로 갱신합니다. 준비/전투 모드의 선발 표식 생성 회귀 테스트를 추가했습니다.

수정 후 위셔델을 전장에 포함한 브라우저 재검증 통과: 예상한 주입 오류 1개 이외 오류 0개, 종료 후 파티클/링/숫자 0개, 풀의 가시 파티클 0개, 기물 18개의 위치 오차·들림·보간 0. 준비·읽기 전용 전환을 포함합니다. 최종 관련 단위 테스트 106개 통과. 위의 완료 스크린샷은 선발 포함 결과로 갱신했습니다.

### 다단 공격의 장비 효과와 대미지 텍스트 위치

- 장비의 공격 이벤트를 개별 타격 그룹으로 전달합니다. 공격 1회의 일반 재능 이벤트·공격 횟수·SP·탄약 처리는 한 번 유지하며, 기존 피해 발생/받는 피해 장비 효과는 원래 각 피해 인스턴스마다 적용되는 경로를 유지합니다. 광역 피해로 별도 공격 이벤트를 추가하지 않습니다.
