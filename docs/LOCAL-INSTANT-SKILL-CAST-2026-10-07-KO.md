# 독립 발동형 스킬의 타격 시점 — 로컬 수정

## 원인

파인콘 1스킬의 onStart가 forceAttack을 즉시 실행하여 스파인의 Skill_1 타격 이벤트를 기다리지 않았습니다. 원본 에셋의 Front/Back Skill_1은 총 1.3초, 첫 OnAttack은 0.467초입니다. 추가로 스킬별 공격 타격 정보를 읽는 함수가 존재하지 않는 SkillRuntime.index를 참조하여 일반 공격 시간으로 대체되는 문제를 발견했습니다. 정상적인 def.skill.index로 수정했습니다.

## 적용

검토한 독립 발동 스킬 21종의 효과를 실제 에셋의 타격 이벤트까지 지연합니다. 일반 공격은 발동 모션 완료까지 대기하며 스킬의 SP 자연 회복도 발동 중에 대기합니다. 사망·재배치 시 남은 예약 효과가 다른 배치에 적용되지 않습니다. 발동 시 코스트를 지급하는 불피스폴리아·플레임테일 2스킬은 코스트 지급을 분리하여 즉시 유지합니다. 다음 공격 강화·능력치 버프를 일괄 지연시키지 않습니다. 텍사스 2스킬의 기존 명시적 2초 발동 처리를 유지합니다.

아래는 기본·선택 가능한 스킬의 즉시/충전형 onStart 처리 감사입니다. 에셋에 검증 가능한 타격 메타데이터가 없는 항목에는 임의 지연을 추가하지 않았습니다. 다중 타격의 매 회차 간격과 투사체 비행시간까지 원작과 일치한다고 주장하는 검증은 아닙니다. 이번 변경은 독립 발동 효과가 모션 시작 즉시 발생하던 문제를 대상으로 합니다.

## 검증과 범위

관련 테스트 330개 통과. 실제 Chromium에서도 Skill_1 트랙이 0.4초 선딜레이, 0.467초 타격, 1.15초 후딜레이까지 유지되고 1.35초에는 Idle로 전환됨을 확인했습니다. 브라우저 오류는 없었습니다. 정상·정예 파인콘의 충전 소비, 0.467초 이전 미공격, 일반 공격 쿨타임 중 독립 발동, 모션 후반 일반 공격 방지, 사망 시 취소를 확인했습니다. 23개 오퍼레이터/스킬 구성에서 효과 콜백이 실제 타격 시간 전에는 실행되지 않음을 확인했습니다.

실제 모델 검증 스크립트: `/workspace/artifacts/capture-pinecone-cast.mjs`. 선딜레이·타격·후딜레이·완료 스크린샷: `/workspace/artifacts/pinecone-cast-{windup,impact,recovery,complete}.png`. 시간별 트랙 기록: `/workspace/artifacts/pinecone-cast-browser.json`.

PRTS 파인콘 페이지는 이 세션에서 HTTP 503으로 조회할 수 없었습니다. 시간 수치는 저장된 원본 스파인의 OnAttack 이벤트와 애니메이션 길이에 근거합니다.

0.1.4a 로컬 테스트 패치노트에 반영했으며 커밋·푸시·운영 배포하지 않았습니다.
