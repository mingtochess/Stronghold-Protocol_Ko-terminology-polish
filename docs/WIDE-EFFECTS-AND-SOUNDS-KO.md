# 광역 공격 효과·원본 사운드 추가 점검

- 은재 3스킬·무에나 3스킬: 배치 방향을 따르는 검기 유지. 전달된 실제 범위로 크기를 제한한다.
- 산탄사수·리퍼: 검기 대신 부채꼴 충격파. 이그제큐터의 범위를 임의의 2타일로 추정하던 처리를 제거했다.
- 진법술사(린·카넬리안 등)·모스티마 3스킬: 검기 대신 마법 파동. 캐스터 공격에 흰 칼날을 붙이지 않는다.
- 그 외 전체 범위 공격: `omnidirectional`이라는 이유만으로 검기를 만들지 않는다. 기존 전용 투사체·피격 효과를 유지한다.
- 일반 공격 범위 데이터를 렌더러까지 전달하고, 스킬 중에는 실시간 스킬 타일을 우선 사용한다. 범위 정보가 없으면 임의의 큰 검기를 만들지 않는다.
- 분류 점검 결과는 `WIDE-EFFECT-AUDIT.json`에 저장했다. 이 파일은 데이터와 분류를 점검한 목록이며 모든 스킬을 직접 전투로 검증했다는 의미는 아니다.

원본 사운드:

- 출처: ArknightsAssets/ArknightsAssets2의 voice 브랜치 `audio/sound_beta_2`, 원본 `audio_data.json`의 이벤트 뱅크.
- 기존 일반 공격·피격 뱅크와 334개 스킬의 발동음 연결을 점검했다. 발동 뱅크가 있는 212개는 그대로 연결하며, 없는 122개에 다른 스킬 발동음을 임의로 대입하지 않는다.
- 모스티마·무에나·이그제큐터·이그제큐터 디 엑스 포에데레의 확인된 능력 뱅크를 스킬 중 공격/피격 역할로 연결했다. 현재 데이터에서 7개 스킬이 이 연결을 사용한다.
- 능력 번호를 모든 오퍼레이터의 스킬 번호로 간주하지 않는다. 나머지 스킬의 별도 공격 뱅크는 추가 대조가 필요하며, 전체 전용 사운드 적용 완료로 간주하지 않는다.
- 공격음의 재생 시점은 `atk`, 피격음은 기존 `dmg` 이벤트를 유지한다. 발사 후 스킬이 끝나도 해당 투사체 피격음은 발사 때의 스킬 모드를 유지한다.
- 이번 리소스 목록의 원본 음원 59개 다운로드를 확인했다. 변경 사항은 로컬에만 적용했다.

검증: 렌더링·오디오 테스트 550개 통과, 3개 건너뛰기. 스킬 종료 후 피격음, 범위 누락 시 과도한 효과 생성 방지를 회귀 테스트로 확인했다. 원본 게임과 모든 스킬의 화면·사운드를 일대일 재현해 대조한 것은 아니다.
