# 로컬 관전·대미지·스킬 발동 수정

- 관전 대기석: 준비 전장에 이미 포함된 기물과 장비는 별도 대기석에서 다시 생성하지 않는다. 협력·보스전처럼 전장에 대기석이 없는 경우에는 별도 표시를 유지한다. 슬롯 위치와 관전 대상별 소유권을 보존한다.
- 대미지 표시: 개별 피해 이벤트의 표시 ID를 사용해 같은 이벤트의 반복 수신을 차단한다. 실제로 발생한 동일 수치의 여러 타격은 모두 표시한다. 운영 환경에서 중복 수신이 발생한 원인 자체는 패킷 기록 없이 확정하지 않았다. ID 없는 이전 기록은 그대로 재생한다.
- 대미지 좌우 폭: 타일 너비의 최대 ±3.5%로 축소했다. 브라우저에서 피해 3회를 각각 세 번 전달한 결과 표시 수는 3개였다.
- 스킬 발동: 와일드메인 2스킬, 첸 더 던스트릭 3스킬, 아스트젠 3스킬은 기본 공격 범위가 아니라 발동 후 스킬 범위의 적을 확인한다. 네 방향과 해당 대공 스킬의 공중 대상도 확인했다. 다른 DEFAULT 스킬의 기존 기본 공격 범위 조건과 전용 SKILL_RANGE 조건은 유지한다.
- 적 제국 드론 대상 고정 변경은 제외했다.

검증: 관련 테스트 175개 통과, 골든 검증 6개 통과. 브라우저에서 일반·협력·보스 관전, 대상 전환, 전투 중 대기석 숨김과 피해 표시 중복 방지를 확인했다. 커밋·푸시와 운영 서버 배포는 하지 않았다.
