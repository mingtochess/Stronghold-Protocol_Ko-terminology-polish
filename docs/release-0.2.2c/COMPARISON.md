# 0.2.2c 실제 플레이 변경 비교


- 보스전 적 정보 화면의 예고 구역 바닥을 복구했습니다. 보스전에서는 일반 전장의 GPU 지오메트리 면과 정점을 생성하지 않습니다.
- 보타니의 획득 시 우르수스/기적 중첩 증가를 제거하고, 전투 중 첫 스킬 발동 시 활성화된 우르수스 중첩 +8로 변경했습니다. 승급 시 +16을 적용합니다.
- 드론의 크기 증가를 중첩당 0.5%에서 0.25%로 줄였습니다. 기본 크기 85%는 유지합니다. 6우르수스의 공격력 기여 비율은 그대로이며, 설명만 중첩당 +0.025%p로 바로잡았습니다.
- PR #5·#6·#7 병합: 최소 구성 위반을 선택 시점에 차단하며, 익명 전원 동의 투표로 같은 방 대기실로 돌아갈 수 있습니다. 관전 복귀 문구는 돌아가기로 표시합니다.

- 우르수스 제국 드론의 공격 범위에 중첩당 +0.15% 히든 배율을 추가했습니다. 대상 선정, 조준 추적, 은신 무효화와 관전 범위 표시에 같은 값을 사용하며 폭격 반경은 유지합니다.

- 인사이더처럼 전용 공격 대기 모션이 있는 오퍼레이터는 공격 사이에 무기를 든 자세를 유지합니다. 공격 피해 타이밍과 공격 속도는 유지합니다.

관련 검사 102개 및 공격 범위·스냅샷 검사 44개를 통과했습니다(일부 검사는 중복). 기존 로스터·수치 불일치 검사 6개는 수정 전 파일에서도 실패하는 것을 확인했습니다.
