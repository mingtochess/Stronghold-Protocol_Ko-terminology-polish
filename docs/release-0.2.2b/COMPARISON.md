# 0.2.2b 실제 플레이 변경 비교

| 항목 | 이전 | 수정 후 |
| --- | --- | --- |
| 전투 텍스트·이펙트 | 보스전 시점에 따라 모델과 위치가 어긋남 | 모델과 같은 고정된 월드 좌표로 투사체·조준·피격·회복·무기 잔상과 텍스트를 투영 |
| 고정형 보스 | 주변 오퍼레이터를 가림 | 점유 영역 뒤쪽을 기준으로 그려 옆과 앞의 오퍼레이터가 보임 |
| 한국어 설명 | 잠재능력·모듈 수치 변경 등으로 번역 누락 | 공식 한국어 템플릿과 현재 수치로 표시 대상 설명 보강 및 중복 검사 |
| 완료 화면 | 채팅 없음 | 채팅 열기·전송·닫기 가능 |
| 통계 | 존재하지 않는 언어 API 호출로 오류 발생 | 네 탭 정상 표시 |
| 패치노트 버튼 | 상단 오른쪽 표시 | 방식 선택 화면의 돌아가기·핑 옆 표시 |

전투 규칙용 원문 백업과 글로벌 미출시 콘텐츠는 화면 번역 검사에서 제외했습니다. 보스 영역 전체보다 뒤에 있는 유닛의 앞뒤 순서는 유지합니다.

관련 테스트 121개와 실제 브라우저 시점·채팅·통계·버튼 위치 검증을 통과했습니다. 표시 대상 설명 검사 결과 미번역 및 중복 문장은 0건입니다.

추가 변경:

- 보스전 적 정보 화면의 예고 구역 바닥을 복구했습니다. 보스전에서는 일반 전장의 GPU 지오메트리 면과 정점을 생성하지 않습니다.
- 보타니의 획득 시 우르수스/기적 중첩 증가를 제거하고, 전투 중 첫 스킬 발동 시 활성화된 우르수스 중첩 +8로 변경했습니다. 승급 시 +16을 적용합니다.
- 드론의 크기 증가를 중첩당 0.5%에서 0.25%로 줄였습니다. 기본 크기 85%는 유지합니다. 6우르수스의 공격력 기여 비율은 그대로이며, 설명만 중첩당 +0.025%p로 바로잡았습니다.
- PR #5·#6·#7 병합: 최소 구성 위반을 선택 시점에 차단하며, 익명 전원 동의 투표로 같은 방 대기실로 돌아갈 수 있습니다. 관전 복귀 문구는 돌아가기로 표시합니다.

- 우르수스 제국 드론의 공격 범위에 중첩당 +0.15% 히든 배율을 추가했습니다. 대상 선정, 조준 추적, 은신 무효화와 관전 범위 표시에 같은 값을 사용하며 폭격 반경은 유지합니다.
