# 장판·스킬 육각형·UI 그라데이션 로컬 수정

운영 배포·커밋·푸시 없이 로컬에 적용했다.

- 장판에 반투명한 단색 배경을 추가했다. 생성한 오퍼레이터의 현재 스킬 이름·효과·대표색을 스킬 범위와 같은 `skillRangeStyle`로 해석한다. 일러스트에서 대표색을 추출하는 경우에도 캐시된 같은 색을 사용한다. 장판이 남아 있는 동안 시전자가 사망해도 해당 색 정보는 유지된다. 원 윤곽선은 벡터로 그린다.
- 스킬 발동·사용 중 육각형은 오퍼레이터 고유색을 사용하지 않고 기본 금색 `#FFD45A`를 사용한다. 전장 바닥에서 회전하므로 카메라에 따라 찌그러지는 원근도 유지한다. 초당 약 31.5도로 회전한다. 스킬 종료·사망 시 기존처럼 사라진다.
- 쏜즈 더 로드스타 2스킬은 한 시전의 장판을 매초 새로 생성하던 문제를 수정했다. 시전별 식별자를 서버가 전송하고 클라이언트가 같은 원의 위치·반경·남은 시간을 갱신한다. 한 시전의 원은 하나만 유지하며 점차 커지고 이동한다. 서로 다른 시전은 각자 원을 유지한다. 피해·회복의 기존 주기는 변경하지 않았다.
- 상하단 그라데이션은 게임 UI와 나란한 전체 화면 요소에서 전장 내부 `::after` 레이어로 옮겼다. 전장에 `isolation: isolate`를 적용한다. 전장의 z-index는 0, 내부 그라데이션은 2, HUD는 3이므로 전장 레이어 바깥의 UI를 덮을 수 없다. 이전 화면 코드가 만드는 `.gm__vignette`는 숨겨 중복 그라데이션을 방지한다. 그라데이션 자체는 유지한다.

## 확인

장판·회전 육각형·기존 5단계 오퍼레이터 스킬·발사 완료된 장판형 공격 회귀 검사 94개가 통과했다. 색 선정 후 수정된 렌더러 검사 38개도 다시 통과했다.

실제 렌더러 하네스에서 쏜즈 장판 수는 0·4·8초 모두 1개, 반경은 각각 1.10·1.62·2.14타일이었다. 장판 배경색은 물결 계열 `#65B6CF`로, 스킬 범위와 같은 규칙을 사용한다. 금색 육각형의 회전도 함께 캡처했다.
