# 대기석 복제·과열·충전형 시전 SP바 점검

## 기준

[PRTS 技能](https://prts.wiki/w/技能) 문서의 `特殊属性`를 API로 확인했다.

- 과열(`过载`): 지속시간이 절반 경과하면 추가 효과를 적용한다. 지속 바는 전체가 아니라 절반 구간씩 표시하며, 후반 구간은 빨간색이다. 탄약형은 최초 탄약이 절반 남았을 때 과열에 진입한다.
- 충전(`可充能`): 실제 저장 SP의 상한은 1회 비용 × 최대 충전 횟수다. 시전시간 표시와 실제 저장 SP는 별개다. 지속·탄약·토글 스킬의 SP 회복 차단과 명시적인 SP 회복 불가 상태는 유지한다.

## 수정

- 자신의 준비 화면에서 관전 대기석 패킷으로 별도 복사본을 생성하던 경로를 차단했다. 준비 화면 갱신 때 남아 있는 관전 복사본도 제거한다. 일반 관전과 공유 전장 관전의 누락 대기석 표시 기능은 유지한다. 단순 렌더링 모드에서도 동일하게 처리한다.
- 혼 2·3스킬과 로크로크 2스킬은 과열의 두 구간을 나눠 표시한다. 과열 구간에서는 전장·오퍼레이터 상세창·단순 렌더링 모드의 바가 빨간색이다. 두 구간 사이를 보간해 바가 어색하게 차오르는 현상도 방지한다.
- 기존 혼 3스킬의 공격력·HP 감소와 로크로크의 공격력·드론 한도·종료 후 기절 구현은 유지했다. 혼 2스킬의 추가 마법 피해 판정은 추가 탄약을 포함한 해당 시전의 탄약 상한을 기준으로 수정했다.
- 충전형 즉시 시전 스킬의 시전 애니메이션 중에도 실제 SP는 회복한다. 표시용 바는 시전 잔여시간을 보여주며 타격 이후에도 시전 애니메이션 종료까지 유지한다. 저장 SP·충전 횟수를 표시값으로 덮어쓰지 않는다.

## 검증

자신의 준비 화면, 일반 관전, 협력·보스 관전, 대상 전환, 전투 화면을 브라우저로 점검했다. 과열 색과 바 비율도 브라우저에서 확인했다. 혼·로크로크 효과, 추가 탄약 경계, 실제 SP 회복과 시전 종료, 기존 SP·탄약 표시 테스트를 수행했다. 기존 어스스피릿 테스트의 배치 완료 전 스킬 활성화 가정은 배치가 끝난 뒤 확인하도록 테스트 준비 과정을 수정했다.
