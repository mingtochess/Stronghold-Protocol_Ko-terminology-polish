# 선호 프리셋과 맹약 중첩 알림

오퍼레이터 구성 창과 인게임 상점의 **선호 프리셋** 버튼에서 설정한다. 프리셋을 만들고 이름을 바꾸거나 복제·삭제할 수 있다. 오퍼레이터/장비 탭에서 선택한 목록은 이 브라우저에 자동 저장된다. 활성 프리셋 하나의 목록을 상점과 무료 보상 카드에 별표로 표시한다. 선호 설정은 선발·밴·모집 확률·구매나 장착에 영향을 주지 않는다.

전투 중 맹약 중첩 이벤트에 효과 주인 ID·좌표를 추가했다. 주인이 있는 알림은 해당 위치 위에 표시하며 서로 다른 발동자의 증가를 합쳐 숨기지 않는다. 주인이 없는 이벤트는 기존 화면 알림을 유지한다. 아이콘은 30px, 숫자는 22px로 조정했으며 카메라 변화에 맞춰 위치를 투영한다.

프리셋/이벤트/표시 크기 관련 47개 검사 통과. 프리셋 UI는 Chromium에서 오류 없이 열렸고 PC·모바일 화면을 확인했다. 추가 전투 검사에서는 73개 통과, 1개 기존 실패가 있었다. 실패는 대미지 이벤트 길이를 4로 기대하나 기존 구현이 5를 보내는 검사이며, 수정 전 체크아웃에서도 동일하게 재현됐다.

로컬에만 적용했으며 커밋·푸시·운영 배포는 하지 않았다.
